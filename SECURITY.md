# Security Policy

## Supported Versions

Only the current `main` branch of the Conxian Public Repository Portfolio site is actively maintained and supported.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main`           | :white_check_mark: |

## Reporting a Vulnerability

We take the security of the Conxian ecosystem seriously. If you discover a security vulnerability or sensitive information exposure, please report it responsibly.

### How to Report

1. **Do NOT open a public GitHub issue** for security vulnerabilities or sensitive configuration leaks.
2. Email security reports to `security@conxian.org` or submit via GitHub Private Vulnerability Reporting if enabled on this repository.
3. Include detailed information:
   - Description of the vulnerability or exposed asset
   - Steps to reproduce
   - Potential impact
   - Proposed remediation if available

### Response & SLA

- **Acknowledgment:** Within 48 hours.
- **Assessment & Status Updates:** Within 5 business days.
- **Remediation & Disclosure:** Coordinated disclosure upon verification and fix release.

Thank you for helping keep Conxian secure.
